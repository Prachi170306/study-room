# StudyRoom 📚

A student collaboration and study room platform built using React, Vite, and Firebase.

## 🚀 Features

- User authentication (Sign Up and Login)
- Student onboarding
- User profile management
- Dashboard
- Task management
- Study progress tracking

## 🛠️ Tech Stack

- React.js
- Vite
- Firebase Authentication
- CSS
- JavaScript

## 📁 Project Setup

### 1. Clone the repository

```bash
git clone https://github.com/Prachi170306/study-room
```

### 2. Navigate to the project folder

```bash
cd study-room
```

### 3. Install dependencies

```bash
npm install
```

### 4. Configure Firebase

Create a `.env.local` file in the root directory.

Copy the variables from `.env.example` and add the Firebase configuration values provided by the project administrator.

### 5. Start the development server

```bash
npm run dev
```

Open the local URL displayed in your terminal.

## 🔐 Environment Variables

The project requires these Firebase environment variables:

- `VITE_FIREBASE_API_KEY`
- `VITE_FIREBASE_AUTH_DOMAIN`
- `VITE_FIREBASE_PROJECT_ID`
- `VITE_FIREBASE_STORAGE_BUCKET`
- `VITE_FIREBASE_MESSAGING_SENDER_ID`
- `VITE_FIREBASE_APP_ID`

**Important:** Never commit `.env.local` or share your private configuration through public repositories.
